# Վերադարձրու Ամուլսարը — շարունակական վերելք

Բացիր `veradardzru-amulsary-doodle.html` ֆայլը բրաուզերում։ Խաղը ինքնաբավ է․ գրաֆիկան ներառված է ֆայլում, և խաղալու համար համացանց պետք չէ։ Սա HTML խաղ է։

## Խաղը

Մեկ երկար լեռ, չորս հետազոտական կայան, 1280 հիմնական հարթակ և լրացուցիչ ապահով այլընտրանքներ։ Յուրաքանչյուր գլխում հավաքիր 24 հետք՝ ընդհանուր 96։ Կայանի հարցին պատասխանելուց հետո անմիջապես շարունակում ես նույն տեղից՝ նույն տեսախցիկով, ընդհանուր հաշիվով և անցած ճանապարհով։

Սովորական ցատկը մոտ 206 խաղային միավոր է․ գագաթին հասնում ես 0.625 վայրկյանում, նույն բարձրությանը վերադառնում՝ 1.25 վայրկյանում։ Կարող ես ընտրել մի քանի հարթակներից և հարթակներ բաց թողնել։ Համեմատությունը՝ `DOODLE_REFERENCE.md`։

Անցումը աստիճանական է՝ ավերված, թունավորված հանքի խորհրդանշական պատկերից դեպի մաքրվող և վերջում ծաղկող լեռ։ Ֆոնն ավելի տեսանելի է, բայց շարունակում է մնալ ցածր հակադրությամբ։

Գլուխները՝

1. Ջրի ճանապարհը՝ թթվային կաթիլներ և հոսքեր, քայքայվող հարթակներ։
2. Ցիանիդի հետքը՝ արտահոսող տարաներ և պարբերական արտանետումներ։
3. Փոշու ամպերը՝ քամի, փոշու ամպեր, քարաթափում։
4. Լեռան ապագան՝ նահանջող վտանգներ, բնության նշաններ և կանաչ ավարտ։

Կան նաև անհետացող հարթակներ՝ նախազգուշացնող թուլացմամբ և կողքի պինդ այլընտրանքով։ Մեծ մասամբ քայքայվող հարթակների կողքին նույնպես կա ապահով տարբերակ։ Վերջին գլխի վերջնամասում նոր վտանգներ այլևս չեն ավելանում։

Կառավարում՝ էկրանի կեսերը, ներքևի կոճակները կամ ձախ/աջ սլաքներն ու A/D։ Ցատկն ավտոմատ է։ Ծաղիկ հավաքելիս կերպարը չի թարթում։ Թարթումը միայն վնասի արձագանք է։

## Պահպանում

- `amulsar_doodle_v2`՝ բացված գլուխներ, կերպար և լավագույն հաշիվ։
- `amulsar_doodle_run_v6`՝ ամբողջ երկար վերելքի ընթացիկ վիճակ։
- `amulsar_doodle_checkpoints_v4`՝ նախորդ կայաններում ամրագրված հաշիվ։

Նախորդ կարճ տարբերակի պահպանումը բացվում է համապատասխան նոր գլխի սկզբից․ բացված գլուխները և կերպարը մնում են։ Հին դիրքերը նոր, երկար քարտեզի վրա ուղղակի չեն կիրառվում։ Նոր ընթացիկ վիճակն արդեն պահվում է ամբողջ բարձրությամբ։ «Շարունակել վերելքը» կոճակը վերականգնում է այն։

Պահպանումը կապված է դիտարկիչի և նույն կայքի հասցեի/տեղային ֆայլի միջավայրի հետ։ Այլ դիտարկիչ կամ հասցե տեղափոխելիս այն ինքնաբերաբար չի փոխանցվում։

## Կոդ և կառուցում

- `campaign.js`՝ շարունակական աշխարհի ստեղծում, նոր ֆիզիկա, վտանգներ, կայաններ և պահպանում։
- `engine.js`՝ գրաֆիկայի բեռնում, անիմացիոն ցիկլ, հպումներ և ստեղնաշար։
- `upgrade.py`՝ սկզբնական HTML-ի ինտերֆեյսի պահպանում և ինքնաբավ HTML-ի հավաքում։
- `assets.js`՝ ամբողջական ներկառուցված SVG/WebP գրաֆիկա։
- `ART_PROMPTS.json`՝ ներկառուցված image_gen-ով ստեղծված նկարների պրոմփթներ։

Պատրաստի ներկառուցված գրաֆիկայից վերակառուցելու համար՝

```sh
python3 game-source/build.py
npm run build
```

`assets.js`-ը պարունակում է ամբողջ ներկառուցված SVG/WebP գրաֆիկան։ `build.py`-ը հավաքում է ինքնաբավ HTML-ը և պատճենում `public/game.html`։ Vercel-ի `/game` էջը բացում է այն։

## Փորձարկում

```sh
npm install --no-save playwright
npx playwright install chromium
node game-source/tests/pacing.cjs
node game-source/tests/reference-feel.cjs
node game-source/tests/campaign-mechanics.cjs
node game-source/tests/regression.cjs
node game-source/tests/extra.cjs
node game-source/tests/flower-feedback.cjs
```

Այլ Chromium executable-ի համար՝ `AMULSAR_CHROMIUM_PATH` փոփոխական։ `?test=1`-ում QA գործիքը կառավարում է իրական խաղի նույն ֆիզիկան հաստատուն քայլերով։ Սովորական տարբերակում այն հասանելի չէ։ Ամբողջական խաղարկումները կերպարին չեն տեղափոխում և առարկաները հարկադրաբար չեն հավաքում։ Մեկուսացված բախումների և պահպանման թեստերը օգտագործում են արհեստական պահպանված վիճակներ։

Տեսարանները պայմանական են։ Խաղի օրագրում պահպանված են EPA, USGS և NSW Health սկզբնաղբյուրները։ Վերջնական «Դու փրկեցիր Ամուլսարը» ավարտը խաղային պատմության խորհրդանշական արդյունքն է։

Յուրաքանչյուր գլուխը 320 հիմնական հարթակ ունի։ Ցատկի բարձրությունն ու տևողությունը համապատասխանեցված են բրաուզերային Doodle Jump-ի համամասնություններին։ Հարթակները պահանջում են ձախ/աջ կառավարում։ Ժամանակը ցուցադրվում է գլխի ընթացքում և դրա ավարտին, դադարների ժամանակ չի աճում։ Ռեկորդների վարկանիշ չի ավելացվել։ Հին v3/v4/v5 վերելքերը բացվում են համապատասխան գլխի սկզբից, քանի որ ճանապարհը փոխվել է։
